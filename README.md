# Applied Data Science Workshops

Weekly workshop tasks from the **Applied Data Science** module of my BSc (Hons) Computing with AI at Islington College (London Metropolitan University). Each folder holds Jupyter notebooks that build up from Python basics to data cleaning, statistics and machine learning on real datasets.

## What's Covered
| Workshop | Topics |
|---|---|
| Week 1 | Python fundamentals: lists, sets, dictionaries, built-in functions |
| Week 2 | NumPy: arrays, matrices, reshaping, random numbers |
| Week 3 | pandas Series and DataFrames |
| Week 4 | Data loading, cleaning and selection with pandas (Water Potability dataset) |
| Week 5 | Data visualisation with Matplotlib |
| Week 6 | Statistics: correlation heatmaps, t-tests and z-tests (Housing dataset) |
| Workshop 7 | Machine learning: linear regression (Mobile Price dataset) and logistic regression (Stroke Prediction dataset) |
| Workshop 8 | Working with SQL databases from Python (SQLite, Employee database) |

## Tech Stack
Python · pandas · NumPy · Matplotlib · Seaborn · scikit-learn · statsmodels · SciPy · SQLite · Jupyter Notebook

## Highlights
- Cleaned real-world datasets by handling missing values, converting types and encoding categories
- Built and evaluated **linear regression** (R², MSE) and **logistic regression** (accuracy) models with an 80/20 train-test split
- Ran hypothesis tests (t-tests, z-tests) and visualised correlations with heatmaps

## How to Run
```bash
pip install pandas numpy matplotlib seaborn scikit-learn statsmodels scipy jupyter
jupyter notebook
```
Open any notebook in its workshop folder. The datasets sit next to the notebooks that use them.
